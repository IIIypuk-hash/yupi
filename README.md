# Space Fighter

Браузерная 2D-игра: космический корабль летит через волны врагов и в конце
уничтожает босса с усиленным оружием и большим запасом HP.

- **Бэкенд:** FastAPI (отдаёт статические файлы игры)
- **Фронтенд:** HTML + CSS + JS (Canvas, без фреймворков)

## Геймплей

- Уничтожайте вражеские корабли трёх типов (обычные, стреляющие, зигзагом).
- С части убитых кораблей падают усиления: прокачка оружия (до 3 уровня),
  восстановление HP, временный щит, скорострельность.
- После зачистки волны появляется **босс** — с кратно большим HP и
  атаками по нескольким паттернам (веерный залп, прицельная очередь).
- После победы над боссом открывается следующая, более сложная волна.

## Управление

| Клавиши | Действие |
|---|---|
| Стрелки / WASD | Движение корабля |
| Пробел | Стрельба |
| P | Пауза |

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

После запуска в браузере автоматически откроется `http://127.0.0.1:8000`
с игрой.

## Публикация в Яндекс Игры

См. [YANDEX_PUBLISH.md](YANDEX_PUBLISH.md) — что подготовлено технически
и пошаговая инструкция. Собрать архив для загрузки:
