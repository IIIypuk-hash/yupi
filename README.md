# Docx Uploader

Веб-приложение для загрузки двух `.docx` документов.

- **Бэкенд:** FastAPI
- **Фронтенд:** HTML + CSS + JS (без фреймворков)

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

После запуска в браузере автоматически откроется `http://127.0.0.1:8000`,
где можно перетащить или выбрать два `.docx` файла и загрузить их.
Загруженные файлы сохраняются в папку `uploads/`.
